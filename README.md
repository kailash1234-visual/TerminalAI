# 🤖 TerminalAI

An AI chatbot built with Python and Groq API — available as a terminal app and a live website.

## 🌐 Live Website
👉 [https://mayandifp.onrender.com](https://mayandifp.onrender.com)

## ✨ Features
- Chat with AI in real time
- Remembers conversation history
- Fast responses powered by Groq (LLaMA 3.3 70B)
- Available as terminal app and website

## 🛠️ Tech Stack
- Python
- Flask
- Groq API
- HTML & CSS
- Hosted on Render

## 🚀 Run Locally

### Terminal version
1. Install Python
2. Run: `pip install groq python-dotenv`
3. Create a `.env` file and add: `GROQ_API_KEY=your-key`
4. Run: `python chat.py`

### Website version
1. Install Python
2. Run: `pip install flask flask-cors groq python-dotenv`
3. Create a `.env` file and add: `GROQ_API_KEY=your-key`
4. Run: `python app.py`
5. Open `index.html` in your browser
